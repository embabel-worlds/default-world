How to read financial statements, when a question turns on a computed figure:

- Take each input from the statement that reports it: balances from the balance sheet,
  flows from the income and cash flow statements. Depreciation and amortisation is
  reported in the cash flow statement, not as an income statement line.
- Statements print the current and prior period side by side. Check the column year of
  every figure, and never mix periods in one calculation.
- Where the document defines a metric itself, that definition governs; say which
  definition was used when a metric has common variants.
- Liquidity ratios differ in what counts as liquid: the current ratio takes all current
  assets, the quick ratio excludes inventory and prepaid expenses.
- Metrics named "adjusted" are company-specific and are only meaningful with the
  company's own reconciliation.
- Give the formula alongside the result, so the arithmetic can be checked.
